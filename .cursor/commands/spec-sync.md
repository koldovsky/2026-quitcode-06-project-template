# spec-sync

Прочитай файл `.claude/commands/spec-sync.md` і виконай інструкцію з нього повністю (frontmatter пропусти).
Якщо після назви команди є текст — це адреса репо вимог PM (`<owner>/<repo>`, URL або локальний шлях) замість `$ARGUMENTS`.
Команди терміналу (`git`, `npm`) запускай по одній; push і створення PR — лише після явного «так» людини (крок 7.4).

Єдине джерело інструкції — `.claude/commands/spec-sync.md`; цей файл лише робить команду доступною в Cursor як `/spec-sync`.
